## Unity Asset Store のアセットを使うときの注意

- Asset Store のアセットの多くは **Standard Unity Asset Store EULA**（標準使用許諾契約）で提供されています。
  - 入手先: https://unity.com/legal/as-terms
  - アセットを **ゲームに組み込んで使う** ことは許可されています。
  - アセットの **元データ（モデル・テクスチャなど）だけを再配布する** ことは禁止されています。
- このプロジェクトを授業などで配布する場合は、**配布の形がライセンスの範囲内か** を確認してください。
  - 心配な場合は `Assets/ThirdParty/` を除いて配布し、受け取った人に各自 Asset Store から入手してもらいます。
- 一部の Unity 公式アセットは **Unity Companion License** で提供されています。
  - 入手先: https://unity.com/legal/licenses/unity-companion-license
  - Unity で作るプロジェクトの中で使う場合に限り、利用・改変・配布が認められています。
