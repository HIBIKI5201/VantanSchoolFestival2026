# チュートリアル手順

4 つの Lesson で、Unity の基本操作を身につけます。
各 Lesson には専用のシーンがあります（`Assets/Scenes/`）。

| Lesson | シーン | 覚えること |
| --- | --- | --- |
| 0 | `00_Sample` | 遊んでみる・画面の見方 |
| 1 | `01_Lesson_Parts` | コンポーネントの付け替え |
| 2 | `02_Lesson_Stage` | オブジェクトを置いてステージを作る |
| 3 | `03_Lesson_Debug` | エディタウィンドウで問題を見つけて直す |
| 4 | （自由） | 自分でスクリプトを書く |

---

## Lesson 0：遊んでみよう

1. `Assets/Scenes/00_Sample` を開いて ▶ で再生。
2. 3, 2, 1, GO! の後に WASD で走り、ゴールを目指そう。操作方法は画面左下に表示されています。
3. 自然の中を走る約 1 km（5 分くらい）のコースです。道の両側の **並木** をたどって進もう。
   チェックポイントを **すべて** 通らないとゴールできません。川や湖に落ちると、最後のチェックポイントからやり直しです。
4. もう一度 ▶ を押すと停止します。

| エリア | 内容 |
| --- | --- |
| 01_スタート〜03_加速ストレート | カーブと加速床で操作に慣れる |
| 04_川と細い橋 | 川にかかる細い橋。落ちたら川へドボン |
| 05_丘と谷ジャンプ | 丘を登って、谷をジャンプ台で飛び越える |
| 06_バンパー広場 | ピンクのバンパーにはじかれないように |
| 07_ヘアピン | 急カーブ。DriftDrive だと楽しい |
| 08_湖と動く床 | 湖を渡る動く床。床が来るのを待って乗る |
| 09_ワインディング〜11_ゴール | 登り下りのカーブ、小川の連続ジャンプ、最後の直線 |

> Hierarchy の **Course** を開くと、エリアごとにオブジェクトがまとまっています。
> 地面は **Terrain**（地形）、木と岩は Terrain の **Trees**、水面は **Water** と、水面の少し下に敷いた **KillZone_Water** でできています。
> Terrain を選んで Inspector の筆のアイコン（Paint Terrain）を使うと、地形を盛り上げたり木を植えたりできます。

### 画面の名前を覚えよう

| ウィンドウ | 役割 |
| --- | --- |
| **Hierarchy** | シーンに置いてあるオブジェクトの一覧 |
| **Scene** | シーンを編集する画面（マウスでぐるぐる見回せる） |
| **Game** | プレイヤーが見る画面 |
| **Inspector** | 選んだオブジェクトの部品（コンポーネント）と設定 |
| **Project** | プロジェクトのファイル一覧 |
| **Console** | ログやエラーが表示される |

> **Scene ビューの操作**：右クリックしながら WASD で移動、Alt + 左ドラッグで回転、ホイールでズーム。
> Hierarchy でオブジェクトをダブルクリックすると、そのオブジェクトにズームします。

## Lesson 1：コンポーネントを付け替えよう

`01_Lesson_Parts` を開き、Hierarchy の **RCCar** を選んで Inspector を見てみましょう。

> 💡 各コンポーネントの一番上にある **「▶ このコンポーネントについて」** を開くと、
> その部品が何をするのか・どう使うのかが読めます。わからない部品があったらまず開いてみよう。

### 1-1. 値を変えてみる

1. `Arcade Drive` の **Max Speed** を 15 → 30 にして再生。速くなった？
2. 項目にマウスを乗せると説明（Tooltip）が出ます。ほかの値も変えてみよう。

> ⚠ **再生中に変えた値は、停止すると元に戻ります。**
> 気に入った値はメモしておき、停止してから入れ直しましょう。

### 1-2. 駆動方式を付け替える

1. `Arcade Drive` の右上の **⋮** → **Remove Component** で外す。
2. **Add Component** → **VantanSchoolFestival2026** → **駆動方式** → **ドリフト (DriftDrive)** を付ける。
3. 再生してみよう。滑るようになった？
4. **タンク (TankDrive)** にも替えてみよう。止まったままでも回れる？

| 駆動方式 | 特徴 |
| --- | --- |
| ArcadeDrive | 素直に曲がる。いちばん操作しやすい |
| DriftDrive | 横滑りする。Grip を小さくすると氷の上のよう |
| TankDrive | その場で回転できる |

### 1-3. パーツを追加する

1. **Add Component** → **VantanSchoolFestival2026** → **追加パーツ** → **ジャンプ (JumpParts)** を付けて再生。Space でジャンプ！
2. **ブースト (BoostParts)** も付けてみよう。左 Shift でスピードアップ。
3. **ボディカラー (ColorParts)** を付けて、Targets に車体（Body）をドラッグ、Body Color を変えてみよう。再生しなくても色が変わります。

### 1-4. 操作方法を切り替える

1. 再生中に **Tab** キーを押すと、WASD ⇔ 矢印キー が切り替わります。画面左下の操作方法の表示も変わります。
2. 停止して、Hierarchy の **PlayerController** を選び、**Player Input** → **Default Map** を `DrivingAlt` に変えて再生すると、最初から矢印キー操作になります。
3. `Assets/Settings/RCInputActions` をダブルクリックすると、キー割り当てを自由に変えられます。
   例：Jump を Space から J キーに変えてみよう（変えたら **Save Asset** を押す）。

> 💡 **ポイント**：スクリプトを 1 行も書かずに、部品の組み合わせだけで車の性能や操作が変わりました。
> これが Unity の「コンポーネント」の考え方です。

### 1-5. 車と入力は別のオブジェクト

入力（キーボード）を受け取るのは車ではなく **PlayerController** です。

```
PlayerController（PlayerInput + PlayerCarInput）──「進め」「ジャンプ」──▶ RCCar
```

- PlayerController の **Player Car Input** → **Target Car** に、別の車をドラッグすると、その車を操作できます。
- 車は「誰が命令しているか」を知りません。だから同じ車を AI に運転させることもできます（Lesson 4 のチャレンジ）。

### 1-6. カメラと画面の雰囲気（Unity 公式の機能）

- **FollowCamera**（Cinemachine Camera）が車を追いかけています。
  **Cinemachine Follow** → **Follow Offset** を変えると、カメラの位置が変わります（例：Y を 8 にすると上から見下ろす）。
- **GlobalVolume** の Volume Profile（`Assets/Settings/PostProcessProfile`）で、画面全体の色味を調整しています。
  Bloom（光のにじみ）や Vignette（画面の四隅を暗くする）のチェックを外して、違いを見てみよう。

> Unity には、カメラ（Cinemachine）や画面効果（Volume）のような **公式の機能** がたくさんあります。
> 自分で作る前に、まず公式の機能が無いか調べるのがおすすめです。

## Lesson 2：ステージを作ろう

`02_Lesson_Stage` を開きます。床とスタート地点（と車・PlayerController・GameManager・カメラ・UI）しかありません。
まだゴールが無いので、ステージチェッカーを開くと「ゴール」のエラーが出ます。コースを作ってゴールを置けば消えます。

### 2-1. 部品を置く

1. Project ウィンドウで `Assets/Prefabs/Stage/` を開く。
2. **Floor** を Scene ビューにドラッグ＆ドロップして置く。
3. 上部のツールで動かしてみよう。

| キー | ツール | 使い方 |
| --- | --- | --- |
| W | 移動 | 矢印をドラッグ |
| E | 回転 | 輪っかをドラッグ |
| R | 拡大縮小 | 四角をドラッグ |

> 💡 **Ctrl を押しながらドラッグ**すると、きりのいい数字でピタッと動きます（スナップ）。
> **V を押しながらドラッグ**すると、頂点どうしをくっつけられます（床をすき間なく並べるのに便利）。

### 2-2. コースを作る

使える部品（すべて `Assets/Prefabs/Stage/`）：

| 部品 | 説明 |
| --- | --- |
| Floor | 床 |
| Road | 道路（Floor と同じ形で色だけ違う） |
| Wall | 壁 |
| Guardrail | 低い木の柵（カーブの外側などに） |
| Ramp | 坂（ジャンプ台） |
| SpeedPad | 加速床（矢印の向きに加速） |
| Bumper | ぶつかるとはじき飛ばす |
| MovingFloor | 往復する床 |
| Checkpoint | 中間地点（通過すると落ちてもここから再開） |
| KillZone | 落下ゾーン（コースの下に大きく敷く） |
| Goal | ゴール |

1. 床をつないでコースを作り、最後に **Goal** を置こう。
2. コースの下に **KillZone** を大きく敷こう（Scale を X:200, Z:200 くらいに）。
3. 再生してテストプレイ！
4. 置いた部品を選んで Inspector の値を変えると、その部品だけ性質が変わります（例：SpeedPad の Push Power）。

### 2-3. 保存を忘れずに

**Ctrl + S** でシーンを保存します。タブのシーン名に `*` が付いていたら未保存です。

## Lesson 3：問題を見つけて直そう（デバッグ）

`03_Lesson_Debug` を開いて再生してみましょう。……うまく遊べません！

### 3-1. ステージチェッカーを開く

1. 上部メニュー **VantanSchoolFestival2026** → **ステージチェッカー** を選ぶ。
2. シーンの問題が一覧で表示されます。

| アイコン | 意味 |
| --- | --- |
| ✖（赤） | エラー：このままでは遊べない |
| ⚠（黄） | 警告：遊べるけど困ることがある |
| ℹ（青） | お知らせ |
| ✔（緑） | 問題なし |

### 3-2. 直す

1. **選択** ボタンを押すと、問題のオブジェクトが Hierarchy で選ばれます。
2. まずは **自分の手で** 直してみよう（Inspector でコンポーネントを外す、オブジェクトを削除する など）。
3. わからなければ **修正** ボタンで自動修正もできます。**Ctrl + Z** で元に戻せます。
4. すべて ✔ になったら再生して確認！

> 💡 先生向け：**VantanSchoolFestival2026** → **全シーンをチェック** で、Build Settings のすべてのシーンの結果を Console にまとめて出せます。

### 3-3. Console も見てみよう

再生中の **Console** には `[GameManager] スタート！` などのログが出ます。
エラー（赤いログ）をダブルクリックすると、原因のスクリプトの行が開きます。

## Lesson 4：自分でパーツを作ろう（発展）

### 4-1. 新しい駆動方式を作る

1. `Assets/Scripts/Parts/Drive/` で右クリック → **Create** → **MonoBehaviour Script**、名前を `MyDrive` にする。
2. 中身を次のように書き換える。

```csharp
using UnityEngine;

namespace VantanSchoolFestival2026
{
    /// <summary>自分で作った駆動方式。</summary>
    [AddComponentMenu("VantanSchoolFestival2026/駆動方式/マイドライブ (MyDrive)")]
    [ComponentSummary("自分で作った駆動方式です。", "RCCar に 1 つだけ付けます。")]
    public class MyDrive : DriveBase   // ← DriveBase を継承する
    {
        [Tooltip("進む速さ（メートル/秒）。")]
        [SerializeField] private float _speed = 10f;

        [Tooltip("曲がる速さ（度/秒）。")]
        [SerializeField] private float _turnSpeed = 90f;

        // DriveBase から呼ばれる。ここに「どう走るか」を書く
        protected override void Drive(Vector2 input, float control, float deltaTime)
        {
            SplitVelocity(out Vector3 flat, out Vector3 vertical);

            // 前に進む速度を、そのまま設定する
            flat = transform.forward * (input.y * _speed * Car.SpeedMultiplier);
            Body.linearVelocity = flat + vertical;

            // 曲がる
            Turn(input.x * _turnSpeed * control * deltaTime);
        }
    }
}
```

3. 保存して Unity に戻ると、**Add Component → VantanSchoolFestival2026 → 駆動方式** に「マイドライブ」が増えています！
4. いまの駆動方式を外して、MyDrive を付けて走らせてみよう。

### 4-2. チャレンジ

- アクセルを押していなくても勝手に前に進む「自動走行ドライブ」を作ってみよう。
- `JumpParts.cs` を参考に、ボタンを押すと車が小さくなる「ミニパーツ」を作ってみよう。
  （ヒント：`transform.localScale`）
- `Bumper.cs` を参考に、乗ると上に飛ばされる「トランポリン」を作ってみよう。
- `PlayerCarInput.cs` を参考に、車に「ずっと前進＋ときどきジャンプ」の命令を送る「AI ドライバー」を作ってみよう。
  （ヒント：`RCCar.SetDriveInput()` と `RCCar.RequestJump()` を呼ぶだけ）

> 新しいスクリプトを作ったら [コーディング規約](コーディング規約.md) を見直して、
> `[Tooltip]`・`[AddComponentMenu]`・`[ComponentSummary]` を付けたか確認しましょう。
