# よくある困りごと

## 車が動かない

| 確認すること | 直し方 |
| --- | --- |
| 駆動方式が付いているか | RCCar に ArcadeDrive などを **1 つだけ** 付ける |
| カウントダウン中ではないか | 3, 2, 1, GO! が終わるまで動けない |
| Game ビューを選んでいるか | 再生中に Game ビューを 1 回クリックする |
| PlayerController があるか | `Assets/Prefabs/System/PlayerController` を置く |

迷ったら、メニュー **VantanSchoolFestival2026 → ステージチェッカー** を開きましょう。

## 小さな段差で車が止まる

- 車は **Max Step Height**（標準 0.3 m）までの段差なら、自動で乗り越えます。それより高い段差では止まります。
- RCCar を選んで、Inspector の **Max Step Height** を大きくすると、もっと高い段差も乗り越えられます。
- どこに段差があるかは、ステージチェッカーの **走れる場所を表示** で確かめられます（赤いマスが乗り越えられない段差です）。

## 再生中に変えた値が消えた

再生中の変更は、停止すると元に戻ります。値を決めたら、**停止してから** 入れ直してください。

## すぐに「コースアウト！」になる

- 木と岩の列の外に出ると、Grace Time（標準 2.5 秒）で戻されます。
- 自分で作ったコースで起きる場合は、走る場所が **CourseArea** でおおわれているか確認しましょう。Scene ビューで緑の半透明の箱として見えます。

## カメラが車を追いかけない

**FollowCamera** の **Tracking Target** に車が入っているか確認します。MainCamera に **CinemachineBrain** が付いているかも確認しましょう。

## 日本語が文字化けした

スクリプトは **UTF-8（BOM 付き）** で保存しています。
Visual Studio で文字化けしたときは、「ファイル → 保存オプションの詳細設定」で **Unicode (UTF-8 シグネチャ付き)** を選んで保存し直してください。
詳しくは [コーディング規約](coding-rules.md) を見てください。

## Console に赤いエラーが出た

- エラーをダブルクリックすると、原因のスクリプトの行が開きます。
- よくある原因：`;` の付け忘れ、`{` と `}` の数が合わない、大文字と小文字の間違い、ファイル名と、中に書いた名前（`public class ○○`）が違う。
- **エラーがあるとゲームを再生できません。** まずエラーを 0 にしましょう。

## 「Missing Script」と出る

スクリプトのファイルを消したり名前を変えたりすると、オブジェクトに「見つからないスクリプト」が残ります。
ステージチェッカーの **取り除く** ボタンで消せます。

## マニュアルのウィンドウが開かない

メニュー **VantanSchoolFestival2026 → マニュアル・教材** から開けます。
`docs` フォルダがプロジェクト直下（`Assets` と同じ場所）にあるか確認してください。
