# エディタ拡張（便利な道具）

Unity の画面に、自分で道具を足すことを **エディタ拡張** といいます。
このプロジェクトには、次の 3 つの道具があります。どれもゲームを作るときだけ使う道具で、ゲームそのものには入りません。

## 1. マニュアル・教材

画面の上のメニュー **VantanSchoolFestival2026 → マニュアル・教材** で開きます。

- この教材とマニュアルを、Unity の中で読めます。
- Web 版（GitHub Pages）と **同じファイル** を表示しています。
- 左の目次から読みたいページを選びます。文の中の青い文字をクリックすると、そのページに移動します。
- 「ブラウザで開く」ボタンで、同じページの Web 版を開けます。
- プロジェクトを開いたとき、この画面が開いていなければ自動で開きます。
  自動で開くかどうかは **Edit → Project Settings → VantanSchoolFestival2026** で変えられます（[セットアップ](setup.md) を見てください）。

## 2. ステージチェッカー

画面の上のメニュー **VantanSchoolFestival2026 → ステージチェッカー** で開きます。
今のシーンが「ゲームとして遊べる状態か」を調べて、足りないものを教えてくれます。

| 調べること | 例 |
| --- | --- |
| 車 | 車が 1 台だけあるか、走り方の部品が 1 つ付いているか |
| スタート・ゴール | スタート地点の下に床があるか、ゴールがあるか |
| カメラ | 車を追いかけるカメラがあるか |
| 落ちたとき | 落ちたら戻される場所（KillZone）があるか |
| 画面の表示 | タイムや操作方法が表示されるか |

- **選択** ボタン：問題のあるオブジェクトを Hierarchy で選ぶ
- **修正** ボタン：自動で直す（**Ctrl + Z** で元に戻せる）
- 使い方は [上級 1. 問題を直そう](../advanced/01_debug.md) で練習できます。
- 先生向け：メニュー **VantanSchoolFestival2026 → 全シーンをチェック** で、全部のシーンの結果を Console にまとめて出せます。

### 走れる場所を表示

ステージチェッカーの上のボタン **走れる場所を表示** を押すと、Scene ビューに色付きのマスが出ます。
Scene ビューで見ている場所のまわりを調べて、車が走れるかどうかを色で教えてくれます。

| 色 | 意味 |
| --- | --- |
| 緑 | 走れる |
| 黄 | 段差があるけど、車が自動で乗り越えられる |
| 赤 | 乗り越えられない段差・急すぎる坂（車が止まる・登れない） |
| 紫 | 落ちたら戻される場所（川や湖、KillZone の上） |

- コースを作ったら、赤いマスで道がふさがっていないか確かめましょう。
- 「調べる範囲」「マスの大きさ」「登れる坂」を変えられます。各色のマスの数も表示されます。
- 乗り越えられる段差の高さの目安は、車のタイヤ（WheelCollider_FL などの丸い当たり判定）の大きさから自動で決まります（標準のタイヤで約 0.15 m）。
- ステージチェッカーのウィンドウを閉じると、表示も消えます。

## 3. 部品の説明（このコンポーネントについて）

Inspector で部品を見ると、いちばん上に **「▶ このコンポーネントについて」** が出ます。
開くと、その部品が「何をするか」「どう使うか」「関係する部品」が読めます。

> 💡 これらの道具がどうやって作られているかは、[上級 3. しくみを知ろう](../advanced/03_how-it-works.md) で説明しています。
