# Unity 操作のコツ（ショートカット・便利な置き方）

覚えておくと、Unity の作業がぐっと楽になる操作をまとめました。
最初から全部覚えなくて大丈夫です。困ったときや「もっと速くやりたい」と思ったときに、このページを見に来てください。

> 💡 Mac では、**Ctrl** を **Command（⌘）**、**Alt** を **Option（⌥）** に読みかえてください。

---

## 1. Scene ビューを動かす

マウスのカーソルを **Scene ビューの上に置いてから** 操作します。

| やりたいこと | やり方 |
| --- | --- |
| 見回す（その場で首を振る） | マウスの **右ボタン** を押したまま、マウスを動かす |
| 前後左右に飛び回る | マウスの **右ボタン** を押したまま、**W A S D**（**Q** で下、**E** で上） |
| 速く飛び回る | 右ボタン ＋ W A S D のときに、**Shift** も押す |
| 飛び回る速さを変える | 右ボタンを押したまま、マウスの **ホイール** を回す |
| 近づく・離れる（ズーム） | マウスの **ホイール** を回す |
| 画面を上下左右にずらす | マウスの **ホイールを押し込んだまま** ドラッグ |
| 見ているものの周りをぐるっと回る | **Alt** を押したまま、マウスの **左ボタン** でドラッグ |
| 選んだオブジェクトの所へ飛ぶ | **F** キー（Hierarchy でダブルクリックしても同じ） |
| 選んだオブジェクトを追いかけ続ける | **Shift + F**（再生中に車を追いかけるのに便利） |
| 真上・真横から見る | Scene ビュー右上の矢印（**ギズモ**）の **Y**（真上）・**X** / **Z**（真横）をクリック |
| 遠近感のない見え方に切り替える | ギズモの真ん中の四角をクリック（もう一度押すと戻る） |

---

## 2. オブジェクトを動かす道具

オブジェクトを選んでから、キーで道具を切り替えます（**右ボタンを押していないとき** に押します）。

| キー | 道具 | 使い方 |
| --- | --- | --- |
| Q | 手のひら | Scene ビューをつかんで動かす（オブジェクトは動かない） |
| W | 移動 | 赤（X）・緑（Y）・青（Z）の矢印をドラッグ |
| E | 回転 | 輪っかをドラッグ |
| R | 大きさ | 四角をドラッグ。真ん中の四角で全体を同じ割合で大きくする |
| T | 四角形 | 平らな物の大きさを、辺をつまんで変える |
| Y | まとめて | 移動・回転・大きさを 1 つの道具で |

| キー | できること |
| --- | --- |
| Z | 道具の中心を「オブジェクトの中心（Center）」と「元の位置（Pivot）」で切り替える |
| X | 矢印の向きを「世界の向き（Global）」と「オブジェクトの向き（Local）」で切り替える |

---

## 3. ピタッと置く（スナップ）

床や壁をすき間なく並べたいときに使います。

| やりたいこと | やり方 |
| --- | --- |
| きりのいい数字で動かす（グリッドスナップ） | **Ctrl** を押しながら、移動の矢印をドラッグ |
| きりのいい角度で回す | **Ctrl** を押しながら、回転の輪っかをドラッグ（標準は 15° ずつ） |
| きりのいい割合で大きさを変える | **Ctrl** を押しながら、大きさの四角をドラッグ |
| 角と角をくっつける（頂点スナップ） | **V** を押したまま、くっつけたい角にマウスを合わせてドラッグ |
| 地面や物の表面に乗せる（表面スナップ） | **Ctrl + Shift** を押しながら、移動の道具の真ん中の四角をドラッグ |

- 動かす・回す・大きくする量は、Scene ビュー上部の **グリッドとスナップ** のボタン（方眼のマーク）で変えられます。
- 頂点スナップは、Floor（床）をつなげてコースを作るときにとても便利です。

## 4. オブジェクトを扱う

| やりたいこと | やり方 |
| --- | --- |
| コピーして同じ物をもう 1 つ作る（複製） | **Ctrl + D** |
| 消す | **Delete** |
| 名前を変える | **F2**（Hierarchy で選んでから） |
| 1 つ前に戻す（やり直し） | **Ctrl + Z** |
| 戻したのを、もう一度やる | **Ctrl + Y** |
| 何個かまとめて選ぶ | **Ctrl** を押しながらクリック（Hierarchy でも Scene ビューでも） |
| 表示する / しないを切り替える | **Alt + Shift + A**（Inspector の名前の左のチェックでも同じ） |
| 今見ている場所にオブジェクトを持ってくる | メニューの **GameObject → Move To View**（**Ctrl + Alt + F**） |
| カメラを今の Scene ビューの見え方に合わせる | カメラを選んで **GameObject → Align With View**（**Ctrl + Shift + F**） |
| 空のオブジェクトを作る | **Ctrl + Shift + N** |

> 💡 **Ctrl + D** で複製してから **Ctrl** を押しながら動かすと、同じ部品をきれいに並べられます。

---

## 5. 数字を変えるコツ（Inspector）

| やりたいこと | やり方 |
| --- | --- |
| 数字を少しずつ変える | 項目の **名前** の上でマウスを左右にドラッグ |
| 計算して入れる | 数字の欄に `10*2` のように式を書いて Enter |
| 部品の数字をコピーして別の物に貼る | 部品の右上の **⋮** → **Copy Component**、貼りたい所で **⋮** → **Paste Component Values** |
| 部品の数字を最初の値に戻す | 部品の右上の **⋮** → **Reset** |
| 選ぶ物を変えても Inspector を固定する | Inspector 右上の **カギのマーク** をクリック |

---

## 6. ゲームを動かす・保存する

| やりたいこと | やり方 |
| --- | --- |
| 再生する / 止める | **Ctrl + P**（画面上の ▶ と同じ） |
| 一時停止する | **Ctrl + Shift + P** |
| 一時停止中に 1 コマだけ進める | **Ctrl + Alt + P** |
| シーンを保存する | **Ctrl + S** |
| 今のウィンドウを画面いっぱいにする / 戻す | マウスをウィンドウの上に置いて **Shift + Space** |

> ⚠ **再生中に変えた数字は、止めると元に戻ります。** 数字を決めるときは、止めてから変えましょう。
