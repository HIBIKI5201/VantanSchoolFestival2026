# 上級 1. 問題を直そう

> **このページでやること**：わざと壊してあるシーンを、チェック用の道具「ステージチェッカー」を使って直す。
> **使うシーン**：`Assets/Scenes/03_Lesson_Debug`
> **目安**：15 分（プログラムは書きません）

## 1. まずは遊んでみる

`03_Lesson_Debug` を開いて ▶ を押してみましょう。……うまく遊べません！
どこがおかしいのか、まずは自分の目で探してみましょう。

## 2. ステージチェッカーを開く

1. 画面の上のメニュー **VantanSchoolFestival2026** → **ステージチェッカー** を選びます。
2. シーンの問題が一覧で表示されます。

| しるし | 意味 |
| --- | --- |
| ✖（赤） | このままでは遊べない |
| ⚠（黄） | 遊べるけど、困ることがある |
| ℹ（青） | お知らせ |
| ✔（緑） | 問題なし |

## 3. 直す

1. **選択** ボタンを押すと、問題のあるオブジェクトが Hierarchy で選ばれます。
2. まずは **自分の手で** 直してみましょう。
   - 車が 2 台ある → 片方を選んで **Delete** キーで消す
   - 走り方の部品（駆動方式）が無い → **Add Component** で付ける
   - ゴールが無い → `Assets/Prefabs/Stage/Goal` を置く
   - カメラが車を追いかけない → **FollowCamera** の **Tracking Target** の欄に、Hierarchy から車をドラッグする
3. どうしても分からないときは **修正** ボタンで自動で直せます。**Ctrl + Z** で元に戻せます。
4. 全部 ✔ になったら、▶ で遊べるか確かめましょう。

## 4. Console を見る

画面の下の **Console** には、ゲームからのお知らせが出ます。再生すると `[GameManager] スタート！` などが出てきます。
赤い文字はエラーです。ダブルクリックすると、原因になっているプログラムの場所が開きます。

> ✅ **確認**：ステージチェッカーが全部 ✔ になって、ゴールまで走れましたか？

> 💡 ステージチェッカーのように、Unity の画面に自分で道具を足すことを **エディタ拡張** といいます。
> このステージチェッカーも C# のプログラムで作られています（`Assets/Editor/StageCheckerWindow.cs`）。
