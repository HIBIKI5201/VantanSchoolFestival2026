# 4. 問題を直そう（15 分）

> **この章でやること**：わざと壊してあるシーンを、エディタ拡張「ステージチェッカー」を使って直す。
> **使うシーン**：`Assets/Scenes/03_Lesson_Debug`

## 4-1. まずは遊んでみる（2 分）

`03_Lesson_Debug` を開いて ▶ を押してみましょう。……うまく遊べません！
どこがおかしいのか、自分の目で探してみましょう。

## 4-2. ステージチェッカーを開く（3 分）

1. 上のメニュー **VantanSchoolFestival2026** → **ステージチェッカー** を選びます。
2. シーンの問題が一覧で表示されます。

| アイコン | 意味 |
| --- | --- |
| ✖（赤） | エラー：このままでは遊べない |
| ⚠（黄） | 警告：遊べるけど困ることがある |
| ℹ（青） | お知らせ |
| ✔（緑） | 問題なし |

## 4-3. 直す（8 分）

1. **選択** ボタンを押すと、問題のオブジェクトが Hierarchy で選ばれます。
2. まずは **自分の手で** 直してみましょう。
   - 車が 2 台ある → 1 台を選んで **Delete** キーで消す
   - 駆動方式がない → **Add Component** で付ける
   - ゴールがない → `Assets/Prefabs/Stage/Goal` を置く
   - カメラが車を追いかけない → **FollowCamera** の **Tracking Target** に車をドラッグする
3. どうしてもわからないときは **修正** ボタンで自動で直せます。**Ctrl + Z** で元に戻せます。
4. すべて ✔ になったら、▶ で遊べるか確認しましょう。

## 4-4. Console を見る（2 分）

再生中の **Console** には `[GameManager] スタート！` のようなログが出ます。
赤いエラーをダブルクリックすると、原因のスクリプトの行が開きます。

> ✅ **確認**：ステージチェッカーが全部 ✔ になって、ゴールまで走れましたか？

> 💡 **エディタ拡張** は、Unity のエディタに自分で機能を足す仕組みです。
> ステージチェッカーも C# で作られています（`Assets/Editor/StageCheckerWindow.cs`）。
