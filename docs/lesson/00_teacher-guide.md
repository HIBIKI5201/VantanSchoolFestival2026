# 授業の進め方（先生用）

Unity もプログラミングも初めての人が、ラジコンカーのゲームを触りながら Unity の基本操作に慣れるための授業です。
**内容は 70 分**です。授業の枠が 90 分なら、残りの 20 分は質問や遅れている人のフォローに使ってください。

## ねらい

授業が終わったとき、受講者が次のことをできるようになるのが目標です。

1. Unity の主な画面（Hierarchy・Scene・Inspector・Project）がどれか分かる
2. **コンポーネント**（部品）を付けたり外したりして、車の動きを変えられる
3. **プレハブ**（作り置きの部品）を置いて、自分のコースを作れる
4. 作ったコースで遊んで、友だちと見せ合える

プログラミング（コードを書くこと）はしません。もっとやりたい人には、上級者向けの [問題を直そう](../advanced/01_debug.md)・[スクリプトを書こう](../advanced/02_script.md) を案内してください。

## 覚える Unity 用語

授業の中で出てくる Unity の用語は、次の 7 つだけです。ほかの難しい言葉は使いません。

| 用語 | ひとことで |
| --- | --- |
| シーン | ゲームの 1 つの場面（ステージ） |
| オブジェクト | シーンに置いてあるもの 1 つ 1 つ（車・床・木・カメラなど）。**Hierarchy に並んでいる 1 行 1 行がオブジェクト** |
| Hierarchy（ヒエラルキー） | シーンにあるオブジェクトの一覧の画面。ここで選んだオブジェクトの中身が Inspector に出る |
| コンポーネント | オブジェクトに付ける部品。付けるとできることが増える |
| プレハブ | 作り置きの部品。ドラッグするだけで何個でも置ける |
| Inspector（インスペクター） | 選んだオブジェクトの部品と、その設定が並ぶ画面 |
| 再生（▶） | ゲームを動かしてみること |

## 準備（授業の前日まで）

| やること | 確認 |
| --- | --- |
| Unity Hub と **Unity 6000.3.10f1** をインストールする | Hub の Installs に表示される |
| このプロジェクトを各 PC に置き、一度開いておく | 初回は開くのに数分かかるので、授業前に済ませる |
| `00_Sample` を開いて ▶ で遊べるか確認する | 3, 2, 1, GO! が出て、W A S D で走れる |
| （任意）ゲームパッドを用意する | なくても授業はできる |

## タイムテーブル（70 分）

| 時間 | 章 | シーン | 内容 | 先生のポイント |
| --- | --- | --- | --- | --- |
| 0:00〜0:10 | [1. はじめよう](01_intro.md) | 00_Sample | 遊んでみる・画面の名前 | まず遊ばせて「作ってみたい」と思わせる |
| 0:10〜0:30 | [2. 車を改造しよう](02_components.md) | 01_Lesson_Parts | 数字を変える・部品を付け替える | 「部品を変えるだけで動きが変わる」を体験させる |
| 0:30〜0:50 | [3. コースを作ろう](03_stage.md) | 02_Lesson_Stage | 部品を置く・動かす・ゴールまでつなぐ | 移動 / 回転 / 大きさのキー（W / E / R）を全員で練習 |
| 0:50〜1:10 | [4. コースを仕上げて遊ぼう](04_finish.md) | 02_Lesson_Stage | 仕掛け・飾り・チェックポイント・見せ合い | 隣の人と遊び合う時間を必ずとる |
| （残り時間） | [まとめ](05_wrapup.md) | — | ふりかえり・家でできること | 1 人 1 つ「できたこと」を言ってもらう |

## 時間が足りないとき・余ったとき

- **足りないとき**：4 章の「飾り」を省略して、チェックポイントと見せ合いだけやる。
- **余ったとき**：上級者向けの [問題を直そう](../advanced/01_debug.md) に進む（プログラムは書かない内容です）。

## つまずきやすいポイント

| 症状 | 原因と対応 |
| --- | --- |
| 再生中に変えた数字が消えた | 再生中の変更は、止めると元に戻る。**止めてから** 変えるよう伝える |
| 車が動かない | 駆動方式（ArcadeDrive など）が付いていない、または 2 つ付いている |
| キーを押しても反応しない | Game の画面をクリックしていない。再生中に Game の画面を 1 回クリックする |
| 置いた床が見つからない | Hierarchy でその床をダブルクリックすると、その場所に移動できる |
| 間違えて消してしまった | **Ctrl + Z** で元に戻せる |
| 日本語が文字化けした | [よくある困りごと](../manual/faq.md) を参照 |
