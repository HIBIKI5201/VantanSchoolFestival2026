# 授業の進め方（先生用）

90 分の授業で、Unity を初めて触る人が「コンポーネント」「プレハブ」「エディタでのデバッグ」を体験できるようにする進め方です。

## ねらい

授業が終わったとき、受講者が次のことをできるようになるのが目標です。

1. Unity の主なウィンドウ（Hierarchy・Scene・Inspector・Project・Console）の役割を説明できる
2. コンポーネントを付けたり外したりして、オブジェクトの動きが変わることを体験する
3. プレハブを置いて、自分でコース（ステージ）を作れる
4. エラーや警告を見て、原因のオブジェクトを探して直せる
5. （発展）短いスクリプトを書いて、新しいコンポーネントを作れる

## 対象

- Unity を触ったことがない人（中学生〜）
- プログラミング経験は無くてもよい（5 章だけ少しコードを書きます）

## 準備（授業の前日まで）

| やること | 確認 |
| --- | --- |
| Unity Hub と **Unity 6000.3.10f1** をインストールする | Hub の Installs に表示される |
| このプロジェクトを各 PC に置き、一度開いておく | 初回はインポートに数分かかるため、授業前に済ませる |
| `00_Sample` を開いて ▶ で遊べるか確認する | 3, 2, 1, GO! が出て、WASD で走れる |
| メニュー **VantanSchoolFestival2026 → 全シーンをチェック** を実行する | Console で 00・01 がエラー 0 件 |
| （任意）ゲームパッドを用意する | なくても授業はできる |

> 💡 配布用には、授業前の状態に戻せるように **Git のブランチ** や **zip** を用意しておくと安心です。

## 時間が足りないとき・余ったとき

- **足りないとき**：5 章を省略して、6 章で「家でやってみよう」と紹介する。
- **余ったとき**：3 章で作ったコースを隣の人と交換して遊ぶ。5 章のチャレンジに進む。

## つまずきやすいポイント

| 症状 | 原因と対応 |
| --- | --- |
| 再生中に変えた値が消えた | 再生中の変更は停止すると戻る。**停止してから** 変えるよう伝える |
| 車が動かない | 駆動方式が付いていない／2 つ付いている。ステージチェッカーで確認 |
| キーを押しても反応しない | Game ビューをクリックしていない（フォーカスが Scene にある） |
| 置いた床が見つからない | Hierarchy でダブルクリックすると、その場所にカメラが飛ぶ |
| 日本語が文字化けした | [よくある困りごと](../manual/faq.md) を参照 |
