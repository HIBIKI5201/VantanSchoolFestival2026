# 6. まとめ（10 分）

> **この章でやること**：今日やったことをふりかえって、家で続けるための方法を知る。

## 6-1. 今日やったこと（3 分）

| 章 | やったこと | Unity の考え方 |
| --- | --- | --- |
| 1 | 画面の名前を覚えて遊んだ | **シーン** と **ウィンドウ** |
| 2 | 部品を付け替えて車を改造した | **コンポーネント** |
| 3 | 部品を置いてコースを作った | **プレハブ** |
| 4 | ステージチェッカーで問題を直した | **デバッグ** と **エディタ拡張** |
| 5 | スクリプトで新しい部品を作った | **C# スクリプト** と **継承** |

## 6-2. 発表しよう（5 分）

1 人 1 つ、次のどれかを話してみましょう。

- いちばん面白かった改造
- 自分で作ったコースの見どころ
- 難しかったところと、どうやって解決したか

## 6-3. 家でやってみよう（2 分）

このプロジェクトは持ち帰って続けられます。

- **このマニュアル** は Unity のメニュー **VantanSchoolFestival2026 → マニュアル・教材** からいつでも読めます。
- スクリプトには日本語で詳しい説明（コメント）が書いてあります。`Assets/Scripts/` を開いて読んでみましょう。
- 部品の説明は、Inspector の **「▶ このコンポーネントについて」** で読めます。
- 5 章の **チャレンジ** に挑戦してみましょう。
